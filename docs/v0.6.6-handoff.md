## Known issues / leftover concerns

1. **wflow not redeployed**: wflow proxy is stale (old address, possibly corrupted state). UI shows wflow but transactions are disabled. Deploy fresh JanusERC20 proxy with WFLOW9 underlying before enabling wflow on mainnet.

2. **JanusFT/MockFT Cadence**: Reusing testnet-claucondor (0x7599043aea001283) deployment. No fresh Cadence contract deployed on the new admin account. MockFT is testnet-only by design.

3. **adminResetSlot in production code**: The function is gated by `block.chainid == 545` and reverts on mainnet. Clean but should be removed in a future upgrade.

4. **OFAC compliance hook**: REQUIRED before mainnet per `mainnet-compliance-ofac` memory. Not in current contracts. See MAINNET_DEPLOY_PLAYBOOK.md.

5. **Snapshot recovery not tested in E2E**: The E2E script verifies proof correctness and on-chain state but does not scan events to decrypt recipient notes (recipient privkeys are unknown in the test environment since they're sim accounts). Recipient note encryption is tested indirectly — the shieldedTransfer succeeds on-chain which requires valid note ciphertext.
